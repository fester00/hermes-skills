# BaoYu Content Generation

Generate educational and informational creative content using the BaoYu creative system.

---

## 1. Knowledge Comics (知识漫画)

Create educational comics combining text, illustration, and narrative.

### When to Use
- Explaining complex topics visually (science, history, philosophy)
- Biography or profile storytelling
- Tutorial walkthroughs with visual steps
- Any content where "show, don't tell" improves retention

### Output Format
- Panel-based structure with captions
- Character/dialogue-driven explanations
- Visual metaphors for abstract concepts

**See `references/baoyu-comic.md` for full panel layout options, character generation prompts, and story arc templates.**

---

## 2. Infographics (信息图)

Generate data visualizations and information designs in multiple layouts and styles.

### When to Use
- Presenting statistics or survey results
- Timelines, comparisons, hierarchies
- Process flows, decision trees
- Any data that benefits from structured visual representation

### Layouts
21 layout types including: comparison, timeline, process, hierarchy, network, geographic, funnel, pyramid, cycle, matrix, and more.

### Styles
21 visual styles ranging from flat/minimal to hand-drawn to corporate to dark/edgy.

**See `references/baoyu-infographic.md` for the full layout × style matrix, data preparation checklist, and generation prompt templates.**
