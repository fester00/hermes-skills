# Замена фона: ИИ-маска + композит

Две стратегии и их цена. Выбор делается по разбору кадра глазами (`vision_analyze`), а не по желанию пользователя «вырежи людей».

## A. Заменить только стену (работает почти всегда)

Оставляем объект, воду, пену, борт ванны — меняем только плоскость за ними. Выглядит правдоподобно, потому что линия опоры и тени остаются на месте.

1. PhotoCraft headless, MCP:
   ```
   doc_open(path="<фото внутри automation-read-root>")
   command_run(id="select.subject")            # ИИ-выделение, работает без GUI
   command_run(id="layer.new.layerViaCopy")    # объект -> отдельный слой
   command_run(id="layer.setProps", params={"layer": <id исходного>, "visible": false})
   doc_export(path="work/subject_cutout.png", format="png")   # альфа = маска
   ```
   `doc_inspect` даёт id слоёв и `bounds` выделения — по ним видно, что именно ИИ считает объектом.
2. Фон привести к геометрии фото заранее (PIL): взять из исходного фона вертикальный кроп 3:4 и ресайз в размер фото — так композит не требует трансформаций внутри редактора.
3. Композит в PIL: `Image.composite(bg, orig, mask)`, где `mask` — альфа вырезки.

### Ловушка: ИИ считает «фоном» размытый передний план

На фото «люди в ванне» `select.subject` пометила размытую воду у нижней кромки фоном, и подложка проступила полосой поверх воды. Лечение — не на глаз, а по профилю прозрачности:

```python
a = np.array(cut.split()[3])
trans = (a < 10)
rows = trans.sum(axis=1)                 # где маска реально прозрачна
# строки ниже «дна объекта», где прозрачность появилась снова, — ложный фон
mask = trans.copy(); mask[CLAMP:, :] = False
```

Строка отсечки берётся из этого профиля (в том кадре — 1135), а не из предположений: ниже неё на обеих сторонах остаются пиксели оригинала, поэтому горизонтальный шов невидим.

### Ловушка: светлая кромка старого фона по краю объекта

На границе волос остаётся кайма старой стены. Лечится расширением маски и мягким краем:

```python
m = m.filter(ImageFilter.MaxFilter(5))      # дилатация ~2px
m = m.filter(ImageFilter.GaussianBlur(2.0)) # мягкий переход
```

Порядок важен: сначала дилатация (съедает кайму), потом блюр. Блюр без дилатации кайму только размазывает.

## B. Полная вырезка объекта (когда без вариантов)

Годится для контрастного объекта без мелких полупрозрачных деталей. Пена, брызги, летящие волосы, стекло дают рваные края — если пользователь настаивает, предупредить и всё равно проверить кропами 3×.

## Что проверить перед отправкой

- Кроп 3× по краю объекта (волосы, плечи, линия опоры) — нет каймы и ступенек.
- Полный кадр — фон не «просвечивает» в тенях и между пальцами.
- Сравнение до/после с одинаковым кропом.
- В ответе: какая стратегия выбрана и почему, что осталось на месте, где остался слабый ореол (если остался).

## Смежное

- Один экземпляр библиотеки/каталога на процесс: замок библиотеки держит либо GUI, либо фоновый потомок агента, и сообщение называет только pid — для работы с запущенным окном нужен режим `--control` + `--connect` (навык `headless-desktop-apps`).
- `file.placeEmbedded` в automation-режиме PhotoCraft отключён («uses ambient filesystem paths») — вставку картинки делать через `doc_open` + композит в PIL, а не через команду редактора.
