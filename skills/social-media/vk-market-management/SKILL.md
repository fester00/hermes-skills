# VK Market — импорт и управление товарами

Навык покрывает управление товарным каталогом сообщества VK: импорт через YML,
обновление цен, группировка вариантов и очистка устаревших позиций.

## Предпочтения пользователя

- **Не использовать browser automation (CDP) без явного согласия.** Пользователь
  ранее останавливал CDP-попытки с VK Market как «тяжёлая задача».
- Предпочтительные пути: генерация YML-файла + ручной импорт через админку VK,
  либо VK API (`market.add`).

## Формат YML для VK Market

VK принимает YML-фид (Yandex Market Language) со своими нюансами:

- **Корневой элемент:** `yml_catalog` с атрибутом `date`
- **Внутри:** `<shop>` → `<name>`, `<company>`, `<url>`, `<currencies>`, `<categories>`, `<offers>`
- **Каждый offer:**
  - `id` — уникальный
  - `available="true"` — обязательно
  - `group_id` — для группировки вариантов (разные фасовки одного товара)
  - `<price>`, `<currencyId>RUB</currencyId>`
  - `<categoryId>` — ссылка на `<category>`
  - `<name>`, `<description>`
  - `<param name="Вес/объём">` — для характеристик
  - `<picture></picture>` — placeholder если картинок ещё нет

### Пример минимального offer
```xml
<offer id="junisil_9110_1040" available="true" group_id="junisil_9110">
  <price>2809</price>
  <currencyId>RUB</currencyId>
  <categoryId>1</categoryId>
  <name>Юнисил 9110 — 1.04 кг</name>
  <description>Двухкомпонентный силиконовый компаунд</description>
  <param name="Вес/объём">1.04 кг</param>
  <picture></picture>
</offer>
```

## Пошаговый workflow

### 1. Сбор данных
- Парсить сайт (например страница /price) → список: название, цена, фасовка
- Или получить данные от пользователя
- **Питфолл:** Перед генерацией YML — проверить, нет ли уже готового фида в проекте:
  ```bash
  find ~ -maxdepth 2 -name "*vk*" \( -name "*.xml" -o -name "*.yml" \) 2>/dev/null
  ```
  Найденные файлы (`pentajunior_vk_v3.xml` и т.п.) — сравнить цены с сайтом, обновить при необходимости, затем импортировать.

### 2. Генерация YML
- Использовать Python + `xml.etree.ElementTree` или f-strings
- Группировать варианты под одним `<group_id>`
- Кодировка: `utf-8`
- Валюта: `RUB` (VK принимает RUB, а не RUR)

### 3. Важный питфолл: расширение файла
> **VK отклоняет файл с расширением `.xml`. Нужно `.yml`.**
> Даже если содержимое идентично — сохранять строго с расширением `.yml`.

### 4. Требования к `id` и `group_id` — критично для схемы
> **offer id может содержать ТОЛЬКО цифры и дефис `-`.**
> Любые буквы, подчёркивания `_`, точки `.` — ломают XML-схему VK.

> **group_id ставить ТОЛЬКО у товаров с вариантами** (2+ фасовки).
> У одиночных товаров атрибут `group_id` должен отсутствовать полностью.
> Идентификатор `group_id` тоже должен быть числовым.

Пример правильных ID:
```xml
<!-- Одиночный товар — без group_id -->
<ofer id="100001" available="true">

<!-- Варианты — с group_id -->
<ofer id="100002-1" available="true" group_id="100002">
<ofer id="100002-2" available="true" group_id="100002">
```

### 5. Поддерживаемые символы в тексте
- **Убрать `®` и другие спецсимволы** из `name` и `description`
- Не использовать `(R)` в названиях товаров
- Допустимы буквы, цифры, пробелы, дефис, скобки, запятые

### 6. Доставка файла
- Скопировать файл в user-домашний каталог для удобства скачивания
- Отправить через Telegram/чат как MEDIA:/path/to/file.yml
- Пользователь загружает вручную через админку VK:
  Сообщество → Товары → Импорт товаров → выбрать файл

### 5. Очистка старых товаров
- После успешного импорта — удалить старые товары с неверными ценами
- Можно через VK API (`market.delete`) или через админку

## Альтернативы YML-импорту

| Способ | Когда использовать | Сложность |
|--------|-------------------|-----------|
| YML-файл + ручной импорт | Разовый импорт, <100 товаров | Низкая |
| VK API `market.add` | Регулярное обновление, cron | Средняя (нужен токен) |
| Browser automation (CDP) | Только если API недоступен | Высокая, нестабильна |

## Питфоллы

1. **Расширение `.xml` не принимается** — VK требует `.yml`
2. **VK не достаёт до localhost** — для импорта по URL нужен публичный хостинг
3. **Туннели (`localtunnel`, `ngrok`)** — часто не работают в VK, лучше отдавать файл напрямую
4. **Фасовки одного товара** — обязательно использовать `group_id`, иначе VK создаёт дубли
5. **Пустые `<picture>`** — VK примет, но товар будет без фото; загрузить картинки отдельно
