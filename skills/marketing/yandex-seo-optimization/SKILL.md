# Yandex SEO Optimization

SEO-оптимизация для Яндекса на основе официальных рекомендаций Яндекс Вебмастера и актуальных факторов ранжирования (2025–2026). Навык обновлён после исследования 15+ источников (июнь 2026).

## Overview

Этот навык содержит свод правил и практик, которые влияют на ранжирование сайта в Яндексе. Основной источник — официальная документация Яндекс Вебмастера (`yandex.ru/support/webmaster/ru/...`). Навык помогает провести аудит сайта, понять приоритеты и составить план конкретных действий.

## When to Use

- Пользователь спрашивает: «как улучшить SEO», «как поднять позиции в Яндексе», «что влияет на ранжирование».
- Нужен аудит страницы, категории или всего сайта под Яндекс.
- Работа с SEO-полями в проекте (`page_description`, `seo_text`, `meta_title`, `meta_description`).
- Проверка сайта перед или после изменений структуры, контента, дизайна.
- Внутренняя перелинковка и редактирование SEO-текстов в Next.js + SQLite.
- Подготовка сайта к AI-поиску Яндекса и generative answers.
- Интеграция Yandex Commerce Protocol (YCP) для интернет-магазинов.

Не используй навык для:
- SEO-спама, клоакинга, скрытых текстов, покупных ссылок — эти методы наказуемы.
- Гарантий позиций — Яндекс не гарантирует место в выдаче.
- Чисто декларативных текстов без пользы пользователю.

## Главный принцип: польза для пользователя

Яндекс оценивает сайт через призму полезности. Все нижеперечисленные факторы сводятся к одному вопросу: **решает ли страница задачу пользователя лучше конкурентов?**

## Как работает ранжирование в Яндексе (2025–2026)

- **YATI** — нейросетевая модель, которая оценивает релевантность документа запросу в контексте.
- **MatrixNet / CatBoost** — градиентный бустинг для оценки множества факторов.
- **Комбинаторный подход** — нет единого «главного» фактора; важна совокупность сигналов.
- **Экосистема** — данные из Яндекс.Метрики, Яндекс.Бизнеса, Карт, Дзена, Маркета влияют на доверие и видимость.
- **AI-поиск** — YandexGPT, Алиса, generative answers требуют структурированного контента и могут снижать CTR для информационных запросов.

## 0. Коммерческие факторы (особенно важны для магазинов и услуг)

- Контакты: телефон, адрес, режим работы, карта проезда.
- Отзывы на сайте и внешних площадках (Яндекс.Карты, Отзовик, Яндекс.Маркет).
- Актуальные цены, наличие, ассортимент.
- Доставка, оплата, гарантии, возврат.
- Юридическая информация: ОГРН, ИНН, оферта, политика конфиденциальности.
- Карточка организации в Яндекс.Бизнесе / Яндекс.Картах.
- **Yandex Commerce Protocol (YCP)** — для e-commerce: адаптация товарных данных под AI-поиск и продажи через Алису.

## 1. Качество и уникальность контента

Контент — базовый фактор ранжирования.

### Что работает

- Оригинальные описания товаров, услуг, категорий.
- Тексты, которые отвечают на вопросы пользователей.
- Чёткая структура: H1 → H2 → H3, списки, таблицы.
- Регулярное обновление важных страниц.
- Естественное использование ключевых слов (не перечисление).
- **AI-контент допустим, но после человеческой редакции** — Яндекс фильтрует бесполезный автоматический контент.
- **GEO-оптимизация** — форматирование контента для generative answers (чёткие ответы, FAQ, факты).

### Структура SEO-текстов в шаблонах

- Каждая страница должна иметь **ровно один `<h1>`**.
- SEO-текст категории/подкатегории оборачивай в `<section>` / `<article>` с видимым `<h2>`-заголовком и `aria-labelledby`.
- Внутренние подзаголовки SEO-текста должны начинаться с `<h2>` (если секция уже на уровне H2) или с `<h3>` (если внешняя секция имеет `<h2>`).
- Не храни в БД внешнюю HTML-обёртку (`<section class="category-seo-text">`) — это задача шаблона; иначе получится вложенность секций и дублирование заголовков.
- Если SEO-текст из БД содержит собственный `<h2>`, удали его или сгенерируй заголовок в шаблоне, чтобы избежать двух `<h2>` подряд.

### Что наказуемо (малополезный контент и SEO-спам)

- Скопированный или слегка переписанный текст.
- Автоматически сгенерированный/шаблонный контент без редакции.
- Большие списки поисковых запросов.
- Переоптимизация: избыточное повторение ключевых слов.
- Скрытые тексты (`display: none`, белый текст на белом фоне, микроскопический шрифт).
- SEO-блоки, не несущие ценности пользователю.

> Важно: SEO-текст не запрещён. Запрещены SEO-тексты, ориентированные только на робота и не решающие задачу читателя.

## 2. Техническое здоровье сайта

### Индексация

- Добавить сайт в Яндекс Вебмастер и подтвердить права.
- Создать и загрузить `sitemap.xml`.
- Настроить `robots.txt`: закрыть служебные страницы, дубли, результаты поиска по сайту.
- Использовать директиву `Clean-param` для незначащих параметров URL.
- Важные страницы должны отдавать HTTP 200 OK.
- Несуществующие страницы — HTTP 404, не Soft 404 (страница-заглушка с кодом 200).
- **Страницы больше 10 Мб не индексируются**.
- Корректные заголовки `Last-Modified` / `if-modified-since`.

### URL и структура

- Уникальный и постоянный адрес у каждой страницы.
- Человекопонятные URL (ЧПУ), транслитерация приветствуется.
- Глубина вложенности влияет на скорость индексации: чем глубже, тем дольше.
- Внутренняя перелинковка обычными HTML-ссылками `<a href="...">`.
- JS-навигация, iframe, Flash — не индексируются или индексируются плохо.
- Контент должен быть доступен в HTML без выполнения JS (или использовать HTML-копии).

### Редиректы и канонические адреса

- При смене URL настраивать 301 редирект.
- Выбрать главное зеркало: `www` / без `www`, `http` / `https` — и сообщить через Вебмастер + 301.
- Использовать `rel="canonical"` для дублей.
- Избегать цепочек редиректов и автоматических переадресаций без причины.

## 3. Title, Description и сниппет

- У каждой страницы должен быть уникальный `<title>` и `meta description`.
- Одинаковые title/description на многих страницах — ошибка.
- **Рекомендуемая длина title: 60–70 символов**.
- **Рекомендуемая длина meta description: 120–160 символов**.
- Ключевое слово ближе к началу title.
- Бренд в конце title через разделитель.
- Сниппет формируется автоматически, но качественные title/description повышают кликабельность.
- Настроить фавиконку — она появляется в выдаче.
- Для адресного сниппета: заполнить организацию в Яндекс Бизнесе и Яндекс Картах.
- Open Graph / Twitter Cards — не влияют на ранжирование, но улучшают sharing.

## 4. Мобильная адаптивность и скорость загрузки

- Яндекс проверяет адаптивность отдельным мобильным роботом.
- Предпочтительнее адаптивный дизайн (один URL).
- Если мобильная версия на поддомене (`m.example.com`) — структура должна совпадать с основным доменом.
- Контент не должен выходить за экран, текст должен читаться без масштабирования.
- Не использовать Flash, Silverlight, Applet.
- Разрешить роботу доступ к CSS и JS.
- **Изображения**: конвертируйте исходники в WebP/AVIF, уменьшайте разрешение до разумных размеров. Next.js `next/image` оптимизирует форматы и размеры на лету, но не удаляет тяжёлые исходные файлы из `public/`.
- **Core Web Vitals**: LCP, INP, CLS влияют на UX и косвенно на ранжирование.

## 5. Скорость, доступность, хостинг

- Быстрый и надёжный хостинг.
- Страницы больше 10 Мб не индексируются.
- Корректные HTTP-заголовки, в том числе `Last-Modified`.
- HTTPS и действующий SSL-сертификат.
- Нежелательное ПО, вирусы, скрытые майнеры — повод для санкций.

## 6. Внешние и внутренние ссылки

### Внутренние

- Чёткая ссылочная структура: каждая страница доступна по ссылкам.
- Использовать осмысленный анкор.
- Закрывать от индексации служебные страницы.
- **В SEO-текстах 2–4 естественные внутренние ссылки** на подкатегории и ключевые товары.

### Внешние

- Ссылки должны быть естественными и с авторитетных ресурсов.
- Анкоры внешних ссылок лучше делать осмысленными.
- Спам-каталоги, покупные ссылки, немодерируемые комментарии — риск для репутации.
- Рекламные и партнёрские ссылки помечать `rel="sponsored"`.
- Ссылки от пользователей — `rel="ugc"`.

## 7. Поведенческие факторы и аналитика

Яндекс традиционно сильнее Google учитывает реакцию пользователей, но это не единственный фактор.

- **CTR в выдаче** — кликабельность заголовка и сниппета.
- **Время на сайте** (dwell time) и глубина просмотра.
- **Возврат в выдачу (pogo-sticking)** — быстрый возврат и выбор другого результата = негативный сигнал.
- **Конверсионные действия** — заявки, звонки, добавление в корзину.
- Подключить Яндекс Метрику и настроить цели.
- Вебмастер показывает ИКС (индекс качества сайта) — относительный показатель полезности ресурса.
- Улучшать UX: снижать отказы, помогать пользователю достигать цели.

## 8. Структурированные данные и расширенные сниппеты

- Семантическая разметка помогает Яндексу понять содержимое.
- Поддерживаемые тематики: адреса/организации, вопросы-ответы, программы, фильмы, товары/цены, рецепты и др.
- Форматы: микроформаты, Schema.org, XML-фиды (для больших каталогов).
- Заполнить данные в Яндекс Вебмастере или через Яндекс Бизнес.
- **Yandex Commerce Protocol** — структурированный XML/JSON-фид для товаров, интеграция с Алисой и AI-поиском.

## 9. AI-поиск и GEO-оптимизация (2025–2026)

- **YandexGPT / Алиса / generative answers** — Яндекс показывает структурированные ответы прямо в выдаче.
- Для информационных запросов CTR на классические ссылки может снижаться.
- **Что помогает попасть в AI-ответы:**
  - Чёткие прямые ответы на вопросы (в начале страницы).
  - FAQ с микроразметкой.
  - Нумерованные списки, таблицы, пошаговые инструкции.
  - Структурированные данные (Schema.org Article, FAQPage, HowTo).
  - E-E-A-T сигналы: автор, дата, источники.
- **Yandex Commerce Protocol (YCP)** — новый канал для e-commerce: товары доступны через Алису без перехода на сайт.

## 10. Региональность

- Для локального бизнеса заполнить Яндекс Бизнес.
- Указать регион сайта в Вебмастере.
- Адресный сниппет отображается, если сайт в топ-30 и заполнена карточка организации.

## 11. Диагностика и инструменты Яндекса

Использовать разделы Вебмастера:

- **Диагностика сайта** → Ошибки, Рекомендации.
- **Показатели качества** → ИКС, знаки, сравнение с конкурентами.
- **Индексирование** → Статистика обхода, файлы Sitemap, Переобход страниц.
- **Внешние ссылки**.
- **Поисковые запросы**.
- **Проверка ответа сервера** и **Анализ robots.txt**.

## Практический чек-лист аудита сайта

1. Сайт добавлен в Яндекс Вебмастер, права подтверждены.
2. Настроено главное зеркало и 301 редиректы.
3. Загружен корректный `sitemap.xml`.
4. `robots.txt` закрывает технические страницы.
5. Все важные страницы отдают 200, битые — 404.
6. Уникальные title (≤70 символов) и description (≤160 символов) на всех целевых страницах.
7. Контент оригинальный, полезный, без спама и скрытых текстов.
8. Структура: H1–H3, списки, таблицы, внутренние ссылки.
9. Сайт адаптирован под мобильные устройства.
10. HTTPS работает, сертификат валиден.
11. Подключена Яндекс Метрика.
12. Нет вирусов, редиректов на подозрительные сайты, нежелательного ПО.
13. Для локального бизнеса заполнен Яндекс Бизнес.
14. При смене URL настроены 301 и обновлён Sitemap.
15. Изображения оптимизированы (WebP/AVIF, размеры ≤1600px).
16. Core Web Vitals в зелёной зоне.
17. Внедрена Schema.org микроразметка.
18. SEO-тексты не содержат внешней HTML-обёртки в БД.
19. Для e-commerce рассмотрена интеграция Yandex Commerce Protocol.
20. **Проверить актуальность источников**: при обновлении навыка искать свежие материалы через официальную документацию и проверенные экспертные площадки, см. `references/seo-research-browser-blocks-and-workarounds.md`.

## Актуальные тренды 2025–2026

1. **Нейросетевой поиск и YATI** — Яндекс активнее использует нейросети для понимания смысла.
2. **AI-контент** — автоматически сгенерированный контент под фильтрами, если не несёт реальной пользы.
3. **Голосовой поиск и разговорные запросы** — оптимизация под естественный язык.
4. **Персонализация выдачи** — история пользователя, геолокация, интересы.
5. **YandexGPT и нейросетевые ответы** — возможное снижение органического CTR для информационных запросов.
6. **Усиление борьбы со спамом и манипуляциями ПФ** — регулярные антиспам-апдейты.
7. **Экспертность и авторство** — особенно для YMYL-ниш.
8. **Yandex Commerce Protocol** — новый канал продаж для интернет-магазинов через AI-поиск.
9. **GEO (Generative Engine Optimization)** — оптимизация видимости бренда в generative answers.

## Противоречия между источниками

| Тема | Позиция источников | Разночтения |
|------|-------------------|--------------|
| **Поведенческие факторы** | SEO-сообщество: очень важны. Яндекс: один из многих сигналов. | Степень влияния зависит от ниши. |
| **Длина текста** | Одни — «коротко и по делу». Другие — «топовые страницы длиннее». | Важна не длина, а полнота ответа. |
| **Ссылки** | Эксперты: качество важнее количества. Кейсы: в некоторых нишах ссылки дают быстрый эффект. | Без базовых факторов ссылки работают слабо. |
| **AI-контент** | Яндекс: не против ИИ, но против бесполезного контента. | Ручная доработка обязательна. |
| **YandexGPT и органический трафик** | Эксперты: возможен отток CTR для информационных запросов. | Для коммерческих запросов влияние ограничено. |

## Common Pitfalls

1. **Soft 404**: несуществующая страница отдаёт 200 OK.
2. **JS-only навигация**: робот не видит страницы.
3. **Дубли title/description**: плохо влияет на индексацию и кликабельность.
4. **Переоптимизация SEO-текстов**: риск получить статус «малополезный контент».
5. **Покупные/спамные ссылки**: могут ухудшить, а не улучшить ранжирование.
6. **Игнорирование мобильной версии**.
7. **Долгий отклик сервера и частые падения**.
8. **Изменение URL без 301**.
9. **Дублирование `<h1>` и `<h2>`** на странице.
10. **SEO-текст без семантической секции**.
11. **Неоптимизированные изображения**: тяжёлые PNG/JPG замедляют страницы.
12. **Игнорирование AI-поиска**: классическое SEO недостаточно в 2025–2026.
13. **Отсутствие YCP для e-commerce**: теряется канал продаж через Алису.

## Verification Checklist

- [ ] Проверить сайт в Яндекс Вебмастере: нет ли ошибок и рекомендаций.
- [ ] Проверить уникальность title/description на целевых страницах.
- [ ] Проверить длины title (≤70) и description (≤160).
- [ ] Проверить корректность 404 и отсутствие Soft 404.
- [ ] Проверить мобильную адаптивность через Вебмастер или DevTools.
- [ ] Проверить скорость загрузки ключевых страниц.
- [ ] Проверить robots.txt и sitemap.xml.
- [ ] Проверить HTTPS и срок действия сертификата.
- [ ] Проверить отсутствие дублированного/скопированного контента.
- [ ] Проверить внутренние ссылки: все важные страницы доступны.
- [ ] Проверить Яндекс Метрику и целевые события.
- [ ] Проверить изображения: WebP/AVIF, размеры.
- [ ] Проверить Core Web Vitals.
- [ ] Проверить Schema.org микроразметку.
- [ ] Проверить отсутствие HTML-обёртки SEO-текста в БД.
- [ ] Для e-commerce: проверить возможность YCP.
- [ ] Для информационных страниц: проверить форматирование под AI-ответы (FAQ, прямые ответы).
