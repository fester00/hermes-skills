# Шаблоны SEO-разметки для Next.js + SQLite

Справочник по проверенным на проекте pentajunior-v2 паттернам SEO-разметки.

## 1. Иерархия заголовков

- **Ровно один `<h1>` на страницу.** На товарной странице — название товара. На категории/подкатегории — название раздела.
- **SEO-текст категории** оборачивай в `<section>` с видимым `<h2>` и `aria-labelledby`:

```tsx
<section className="category-seo-text" aria-labelledby="category-seo-heading">
  <h2 id="category-seo-heading" className="h5 mb-3">
    Подробнее о {category.title.toLowerCase()}
  </h2>
  <div dangerouslySetInnerHTML={{ __html: category.seo_text }} />
</section>
```

- Внутренние подзаголовки `seo_text` из БД должны быть `<h2>`, если шаблон уже даёт внешний `<h2>`. Иначе получится `<h2>` внутри `<h2>`-секции — дублирование уровня.

## 2. Антипаттерн: HTML-обёртка в БД

**Не храни в `seo_text` внешнюю обёртку:**

```html
<!-- ПЛОХО: обёртка в БД дублирует шаблон -->
<section class="category-seo-text mt-5 pt-4 border-top" aria-label="...">
  <h2>...</h2>
  ...
</section>
```

**Храни только внутренний контент:**

```html
<!-- ХОРОШО: в БД только семантическое содержимое -->
<p>...</p>
<div class="row g-4 my-1">...</div>
<p>...</p>
```

## 3. Внутренняя перелинковка в SEO-текстах

Каждый SEO-текст должен содержать 2–4 естественные ссылки:
- на подкатегории раздела
- на 1–3 ключевых товара
- на смежные категории, если уместно

Пример анкора:
```html
<a href="/production/silikon-dlya-zalivki-form/silikon-platinovyj-dla-form">Платиновый силикон</a>
```

## 4. Проверки перед commit

1. `npx tsc --noEmit`
2. `npm run build`
3. Открыть страницу в браузере, проверить:
   - один `<h1>`
   - нет дублирующих `<h2>`
   - ссылки кликабельны и ведут куда нужно
   - нет сломанной вёрстки после `dangerouslySetInnerHTML`

## 5. Человеческий стиль SEO-текста

- Не пиши «наслаждайтесь превосходным качеством».
- Давай конкретику: температура, вязкость, пропорции, область применения.
- Завершай призывом к действию: «Свяжитесь с менеджером», «Оставьте заявку».
- Избегай AI-слоупа: «stands as», «underscoring», «vibrant», «testament to», «in the heart of».
