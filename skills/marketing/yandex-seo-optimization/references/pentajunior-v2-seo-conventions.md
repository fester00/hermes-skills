# Проверенные SEO-конвенции pentajunior-v2

Контекст: Next.js 16 + SQLite, каталог силиконовых материалов, SEO под Яндекс.

## Роль навыка

- `yandex-seo-optimization` — основной источник методологии (Вебмастер, длины, приоритеты, факторы ранжирования).
- `pentajunior-v2-seo` — проектный workflow (SQLite-аудит, JSON-LD, build gate, git/deploy).

## Формула keywords

1. **Марка / название товара** — обязательно.
2. **Тип / технология** — `RTV-2`, `платиновый силикон`, `оловянный силикон`, `аэрозольный разделитель`, `ПМС` и т.д.
3. **Целевое применение 1** — задача пользователя.
4. **Целевое применение 2** — дополнительная задача.
5. **Коммерческий/общий запрос** — `купить`, `двухкомпонентный силикон`.

## Title, description и H1

- Title **60–70 символов**. Держать ближе к 60; 70 — допустимый потолок, а не цель.
- Description **160–170 символов (включая пробелы)**. Было выработано в сессии 2026-07-13: раньше лимит считали ≤160, пользователь попросил расширить до 160–170 для лучшей раскрытости сниппета.
- **H1 категорий и подкатегорий** тоже усиливаем функцией/применением, не оставляем только название группы. Хороший H1: `Силикон RTV-2 для заливки форм под гипс, смолы, воск и мыло`, `Разделители и смазки для форм, опалубки и литья ПУ`.
- **Description товаров** целимся в **150–160 символов**, не просто ≤170. Короткое description (<150) — повод добавить второстепенное применение, марку или CTA.
- Description должен усиливать семантическую связь с title, H1, keywords и видимым контентом страницы: повторяться марка/тип/применение, добавляться второстепенные применения и коммерческий сигнал.
- Title ≤70 символов: `Марка — целевое применение/свойство | Пента Юниор`.
- Description: марка, тип, применение, свойство, коммерческий призыв.
- **Слишком короткие метатеги тоже дорабатываем**: title <50–55 символов и description <150–155 символов — повод усилить применение/марку/CTA, пока есть запас до лимита.
- В title/description/keywords **не использовать технические спеки** (Шор А, сСт, мм) — их в карточку товара.

## Контент-ограничения

- **Пищевая/медицинская отрасль / FDA / BfR** — прямые упоминания только для SKU, которым это действительно свойственно. На момент сессий единственный такой продукт — **ТСМ-1** (антипригарный материал).
- **«От производителя»** убираем, если компания не производит. Для дистрибьюторских линеек: «купить», «в Москве», «официальный дистрибьютор ООО «ТЕХГРАНТ»» (для ТЕХМОЛ).
- **Ориентир в keywords — название товара (марка), а не внутренний ID.** ID `-9240` = товар «Юнисил 9240».

## Workflow оптимизации категории

1. git pull.
2. Backup БД.
3. Выгрузить категорию/подкатегории/товары из SQLite.
4. Составить черновик по формуле.
5. Показать черновик, получить «давай».
6. Применить UPDATE, запустить build gate (tsc + npm run build, 156/156).
7. git add pentajunior.db, commit, push.
8. Сообщить, что деплой не делается без команды «задеплой».
