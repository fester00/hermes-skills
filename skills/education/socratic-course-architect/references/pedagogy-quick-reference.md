# Педагогическая шпаргалка для Socratic Course Architect

Конденсированный справочник по learning-science приёмам, которые можно внедрять в сократические курсы.

## 1. Retrieval practice (активное воспоминание)

- **Что:** заставить ученика вспомнить пройденное, не перечитывая.
- **Где в курсе:** точка возврата в конце урока, проверка вспоминанием в карточке модуля, команда `ПОВТОР`.
- **Правило:** вопрос должен быть отвечаемым. Не спрашивай сложное до закрепления базы.

## 2. Spacing effect

- **Что:** повторение через увеличивающиеся интервалы.
- **Где в курсе:** план повторения на 1, 3, 7 дней в финале курса; возврат к ключевым идеям в следующем уроке.

## 3. Interleaving (интерливинг)

- **Что:** чередование похожих, но разных концепций.
- **Где в курсе:** вопрос 2 в карточке модуля — по материалу предыдущего модуля; вопросы, сравнивающие `Pick` vs `Omit`, `Partial` vs `Required`.

## 4. Elaboration

- **Что:** просьба связать идею с собственным опытом или объяснить своими словами.
- **Где в курсе:** самообъяснение во вопросе 2 каждого урока.

## 5. Self-explanation (самообъяснение)

- **Что:** ученик объясняет шаги вслух, как будто другу.
- **Где в курсе:** «Объясни, как будто другу» — обязательный шаг во вопросе 2.
- **Польза:** увеличивает глубину обработки и раскрывает пробелы.

## 6. Concrete examples first (конкретный пример первым)

- **Что:** сначала пример из реального мира, потом абстракция.
- **Где в курсе:** раздел «Контекст Реального Мира» перед вопросами.

## 7. Desirable difficulty

- **Что:** задача требует усилий, но разрешима с подсказкой.
- **Где в курсе:** вопрос 3 (критическое мышление + сравнение/заблуждение).
- **Правило:** не доводить до отчаяния; подсказка должна быть под рукой.

## 8. Formative feedback (формативная обратная связь)

- **Что:** комментарий на процесс, а не только на итог.
- **Где в курсе:** после каждого ответа ученика — признать мышление, уточнить, расширить.

## 9. Scaffolding → Fading

- **Что:** первые задачи — с подсказками, позже — без.
- **Где в курсе:** в инкрементальных drill-сериях; в финале курса — самостоятельное задание.

## 10. Dual coding

- **Что:** одновременное использование текста и визуала.
- **Где в курсе:** ASCII-схемы, дорожные карты, маркированные блоки с эмодзи.

## Метакогнитивная пауза

- **Формулировка:** «Прежде чем идти дальше — как ты думаешь, в чём главная польза этой идеи?»
- **Польза:** учит ученика осознавать, что он знает, и регулировать своё обучение.

## Мост от Знакомого

- **Формулировка:** «Это похоже на... [уже известную ученику идею].»
- **Польза:** снижает когнитивную нагрузку и активирует перенос знаний.

## План Повторения (шаблон)

```
🔄 План Повторения:
• Через 1 день: [1 вопрос на вспоминание]
• Через 3 дня: [1 короткое упражнение]
• Через 7 дней: [1 задача на применение]
```

## Когда что использовать

| Концепция сложная | Использовать |
|---|---|
| Ученик путает похожие идеи | Интерливинг + self-explanation |
| Ученик быстро забывает | Retrieval practice + spacing |
| Ученик пассивен | Metacognitive pause + self-explanation |
| Ученик застрял | Scaffolding + formative feedback |
| Ученику кажется всё понятно | Desirable difficulty + concrete counter-example |
