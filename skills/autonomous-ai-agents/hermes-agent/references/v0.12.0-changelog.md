## Autonomous Curator

- Background agent on gateway cron ticker (7-day cycle)
- Grades skills by rubric, consolidates related, prunes dead
- Reports: `~/.hermes/logs/curator/run.json` + `REPORT.md`
- Bundled/hub skills protected (pinned)
- Model: `auxiliary.curator` (set via `hermes model`)

## Piper TTS — New Local Voice Provider

- Fully local, free
- Install: `pip install piper-tts` (or system package)
- Config: `tts.provider: piper`

## Notable Fixes / Changes

- **Secret redaction OFF by default** — fixes corrupted tool outputs
- **Native multimodal image routing** — routes by model's actual vision capability
- **Gateway media parity** — multi-image + FLAC across Telegram/Discord/Slack/Signal/Email
- **Self-improvement loop** — rubric-based grading, inherits parent runtime, scoped to memory+skills
- **ComfyUI v5 + TouchDesigner-MCP** — bundled by default (was optional)
- **~57% TUI cold start reduction** — lazy init, mtime-cached config, memoized tools
- **Remote model catalog manifest** — new models appear without Hermes update
