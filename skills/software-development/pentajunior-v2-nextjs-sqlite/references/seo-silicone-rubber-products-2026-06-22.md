## Legacy site extraction method

Product table extracted from `https://penta-junior.ru/production/izdelija-iz-silikonovyh-rezin/`:
```js
[...document.querySelectorAll('table tr')]
  .map(tr => [...tr.querySelectorAll('td')]
    .map(td => td.innerText.trim().replace(/\s+/g, ' ')))
```

Links extracted:
```js
[...document.querySelectorAll('table a')]
  .map(a => ({text: a.innerText.trim(), href: a.href}))
```
