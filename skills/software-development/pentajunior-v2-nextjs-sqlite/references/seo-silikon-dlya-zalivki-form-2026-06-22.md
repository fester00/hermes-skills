## Code fix discovered during this session

The category page was rendering the title with a duplicated brand:

```
Силикон для заливки форм — купить двухкомпонентный жидкий силикон | Пента Юниор — Пента Юниор
```

Root cause: `generateMetadata` in `/production/[category]/page.tsx` unconditionally appended ` — Пента Юниор` even when `category.meta_title` already contained the brand. The same anti-pattern existed in the product page.

Fix applied (commit `786dba2`):
- Category: `title = category.meta_title || \`${category.title} — Пента Юниор\`; return { title }`
- Product: `title = product.meta_title || \`${product.title} — Пента Юниор\`; return { title }`

See `references/seo-metadata-checklist.md` § Brand suffix pitfall for the general rule.
