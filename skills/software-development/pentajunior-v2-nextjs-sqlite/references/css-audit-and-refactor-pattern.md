# CSS audit and refactor pattern for pentajunior-v2

## When to use

`src/app/globals.css` has grown large (>70–80 KB), contains duplicate selectors, or is suspected of having unused rules after a redesign or component cleanup.

## Goal of stage 1 (quick wins)

Shrink the file safely without restructuring it into multiple CSS modules. A good stage 1 removes:

1. Unused CSS module files (e.g. `page.module.css`).
2. CSS classes that are defined in `globals.css` but never appear in `className` across the project.
3. Duplicate selector blocks that can be merged.
4. Obvious syntax damage introduced by automated merging.

## Audit script

Run from `/home/natan/pentajunior-v2`:

```python
import re, os

CSS = "src/app/globals.css"
SRC = "src"

with open(CSS) as f:
    css = f.read()

# All class selectors
classes = set(re.findall(r"\.([a-zA-Z_-][a-zA-Z0-9_-]*)", css))

# All className tokens used in TSX/JS
used = set()
for root, _, files in os.walk(SRC):
    for file in files:
        if file.endswith((".tsx", ".ts", ".jsx", ".js")):
            with open(os.path.join(root, file)) as f:
                text = f.read()
            for pat in (
                r'className=["\']([^"\']+)["\']',
                r'className=\{[`"]([^`"]+)[`"]\}',
                r'className=\{[^}]*["\']([^"\']+)["\'][^}]*\}',
            ):
                for m in re.findall(pat, text):
                    used.update(m.split())

# Preserve Bootstrap/state classes that may be generated dynamically
preserve = {
    "css", "ru", "navbar-collapse", "page-item", "page-link",
    "text-bg-primary", "text-bg-success", "is-valid", "is-invalid",
    "is-expanded", "is-rotated", "show-mobile",
}

unused = sorted(classes - used - preserve)
print(f"CSS classes: {len(classes)}")
print(f"Used className tokens: {len(used)}")
print(f"Unused classes: {len(unused)}")
for c in unused:
    print(f"  .{c}")
```

## Removing a class safely

Before deleting any class from `globals.css`, verify it is not:
- A Bootstrap utility class generated by JS logic (`is-valid`, `is-invalid`, `page-item`, etc.).
- A class referenced in `dangerouslySetInnerHTML`, raw HTML strings, or markdown content.
- A class used by a third-party component.

Delete only the classes you can prove are unused.

## Merging duplicate selectors

Find duplicate selectors with:

```python
import re
from collections import defaultdict, Counter

with open("src/app/globals.css") as f:
    css = f.read()

rules = re.findall(r"([^{}]+)\{([^{}]*)\}", css, re.DOTALL)
selectors = []
for sel, _ in rules:
    for s in sel.split(","):
        s = s.strip()
        if s and not s.startswith("@") and s not in {"from", "to"}:
            selectors.append(s)

dups = {k: v for k, v in Counter(selectors).items() if v > 1}
for sel, count in sorted(dups.items(), key=lambda x: -x[1]):
    print(f"{count}x: {sel}")
```

Some duplicates are intentional breakpoint overrides inside `@media` blocks — keep those. Merge only duplicate blocks that are outside media queries and define the same visual state.

When merging, combine properties and let the last declaration win for duplicate keys. Always run the build gate immediately after, because merging can leave broken selectors like:

```css
.spec-table thead th,
}
```

## Forced-reset safety rule (learned 2026-06-23)

If a CSS refactor breaks layout in production, the fastest recovery is:

```bash
cd /home/natan/pentajunior-v2
git fetch origin
git reset --hard <last-known-good-sha>
git push --force-with-lease origin master
```

- Find `<last-known-good-sha>` from the user's statement or `git reflog`.
- Always run the build gate on the recovered commit to confirm the layout is restored.
- Warn the user that `git pull` from another clone will re-download the broken commit until origin is force-pushed to the good SHA.
- After recovery, stage and test the fix in a branch or with incremental changes rather than another mass refactor.

## Git pitfall: backup files

Never run `git add -A` in this repo before a focused commit. The project accumulates SQLite backups (`pentajunior.db.*-backup-*`) and `public/images_backup_*/` directories. If they get staged accidentally:

```bash
git reset HEAD          # unstage everything
git add <intended-files> # stage only the files you meant to change
git status --short | head
```

Always verify `git status` shows only the files you intended to change before committing.
