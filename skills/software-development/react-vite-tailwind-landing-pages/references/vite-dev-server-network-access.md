# Vite dev-server: доступ с другой машины в локальной сети

По умолчанию `npx vite` слушает только `localhost` / `127.0.0.1`. С другой
машины в той же локальной сети открыть `http://<ip>:5173/` не получится —
браузер покажет "не удаётся получить доступ".

## Быстрое решение

Запускаем с `--host`, указывая IP машины в локальной сети:

```bash
cd /path/to/project && npx vite --host 192.168.0.98 --port 5173
```

Вывод Vite:

```
➜  Network: http://192.168.0.98:5173/
```

Теперь с других устройств в локальной сети URL `http://192.168.0.98:5173/`
открывается.

## Альтернативы

- `--host 0.0.0.0` — слушать на всех интерфейсах (удобно, но менее явно;
  используй, если IP машины может меняться).
- `--host` без значения — то же самое, что `0.0.0.0`.

## Подводные камни

- Если порт занят предыдущим dev-сервером, Vite автоматически переключится на
  следующий свободный (например, `5174`). Всегда смотри на URL, который Vite
  выводит в консоль, а не предполагай порт.
- `localhost:5173` с той же машины продолжит работать и при `--host <ip>`.
- Если IP машины неизвестен, получить его быстро:
  ```bash
  hostname -I | awk '{print $1}'
  ```

## В production-превью

Для production preview аналогично:

```bash
npm run preview -- --host 192.168.0.98 --port 4173
```
