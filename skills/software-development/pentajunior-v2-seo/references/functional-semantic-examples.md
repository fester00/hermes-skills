# Функционально-предметная семантика для H1/title/description

Правило, зафиксированное в сессии 2026-07-13: каждый H1, `meta_title` и `meta_description` категории/подкатегории pentajunior-v2 должен содержать не только название группы товаров, но и **конкретное применение** — «для чего используется». Это усиливает семантическую связь между title, description, keywords, H1 и контентом страницы.

## Формула

- **H1:** `Товар/группа + для + применение 1, применение 2 [и применение 3]`
- **title:** `Товар/группа + для + ключевое применение | Пента Юниор` (≤70 символов, целиться в ~60)
- **description:** `Товар/группа + для + перечень применений + ключевые свойства/марки + коммерческий CTA` (160–170 символов включая пробелы)

## Антипримеры (до правки)

- `Силиконовые материалы — компаунды, смазки и герметики от производителя` — нет применения, лишнее «от производителя».
- `Каталог продукции — Пента Юниор` — слишком короткий, нет функции.
- `Герметики` — H1 только название группы, без применения.
- `Средства защиты рук` — нет контекста «для производства/автосервиса».

## Проверка перед применением

1. H1 содержит название группы **и** хотя бы одно конкретное применение.
2. title ≤70 символов; description 160–170 символов.
3. description повторяет ключевые слова title/H1 и добавляет марки/свойства/CTA.
4. Нет «от производителя», если линейка дистрибьюторская.
5. После правок: `npx tsc --noEmit && npm run build`, `seo_jsonld_audit.py`, `global-seo-final-check.py`.
