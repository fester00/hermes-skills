# Рецепт: SEO-проход по одной категории pentajunior-v2

Рабочий паттерн, выработанный в сессиях по категориям «Силикон для заливки форм», «Разделители и смазки для форм», «Силиконовые масла», «Высокотемпературные смазки», «Герметики», «Изделия из силиконовых резин», «Обработка поверхности», «Электроизоляционные компаунды», «СОЖ», «ТСМ-1», «Защита обуви».

## Принципы

- Работаем **по одной категории за раз**: категория → подкатегории → товары.
- Для SEO-источника используем **только `yandex-seo-optimization`** (явное требование пользователя).
- `pentajunior-v2-seo` — проектный workflow: SQLite-аудит, build gate, JSON-LD, git, deploy.
- **Title 60–70 символов** (целиться в ~60, 70 — редкий потолок).
- **Description 160–170 символов (включая пробелы)**. Уточнено в сессии 2026-07-13.
- **Усиливать семантическую связь** между title, description, keywords, H1 и контентом: повторять марку/тип/применение, добавлять второстепенные применения и коммерческий CTA (`купить`, `доставка`, `Москва`).
- **Keywords** — по формуле: `марка` + `тип/термин` + `целевое применение 1` + `целевое применение 2` + `коммерческий/общий термин`.
- **Технические характеристики** (Шор, сСт, диаметры в мм) — в карточку товара, не в keywords.
- **Пищевая/медицинская промышленность** — прямые упоминания только у продуктов, которым это свойственно. На момент сессий единственный такой продукт — **ТСМ-1**.
- **«От производителя»** убираем, если компания не производит. Заменяем на «купить» / «в Москве» / «официальный дистрибьютор ООО «ТЕХГРАНТ»» (для ТЕХМОЛ).
- **Ориентир в keywords — название товара (марка), а не ID.** Например, товар с ID `-9240` называется «Юнисил 9240» — используем «Юнисил 9240».

## Workflow

1. **git pull** — пользователь может сам запушить изменения без предупреждения.
2. **Backup БД:**
   ```bash
   cd /home/natan/pentajunior-v2
   cp pentajunior.db pentajunior.db.seo-<cat>-backup-$(date +%Y%m%d-%H%M%S)
   ```
3. **Выгрузить данные категории из SQLite:**
   ```python
   import sqlite3, json
   conn = sqlite3.connect('/home/natan/pentajunior-v2/pentajunior.db')
   conn.row_factory = sqlite3.Row
   c = conn.cursor()
   cat = c.execute('SELECT * FROM categories WHERE slug=?', (slug,)).fetchone()
   subs = c.execute('SELECT s.* FROM subcategories s JOIN categories c ON s.category_id=c.id WHERE c.slug=?', (slug,)).fetchall()
   prods = c.execute('''SELECT p.*, s.slug as sub_slug FROM products p
     JOIN subcategories s ON p.subcategory_id=s.id
     JOIN categories c ON s.category_id=c.id
     WHERE c.slug=? ORDER BY s.id, p.id''', (slug,)).fetchall()
   ```
4. **Проверить проблемы:**
   - длина `meta_title` > 70 (редко) или < 50–55 (короткий, надо усилить);
   - длина `meta_description` > 170 или < 150 (короткий, надо усилить);
   - семантическая связь title ↔ description ↔ keywords ↔ H1: повторяются ли марка, тип и основные применения;
   - упоминание «от производителя»;
   - упоминания пищевой/медицинской отрасли (кроме ТСМ-1);
   - одинаковые наборы keywords у товаров;
   - технические спецификации в keywords.
5. **Составить черновик** для категории, подкатегорий и товаров.
6. **Показать черновик пользователю**, получить «давай».
7. **Применить UPDATE через Python `sqlite3`.**
8. **Build gate:**
   ```bash
   cd /home/natan/pentajunior-v2
   ./node_modules/.bin/tsc --noEmit
   rm -rf .next tsconfig.tsbuildinfo
   npm run build
   ```
9. **git add pentajunior.db**, commit, push.
10. **Сообщить:** «Изменения запушены. Деплой не делаю без твоего разрешения — скажи «задеплой», когда будешь готов». Ждать именно команду «задеплой».
