# Когда title категории слишком короткий

## Сигнал

`meta_title` категории ≤55 символов и не содержит целевых операций/применений.

Пример из сессии:

- ❌ `СОЖ для металлообработки на станках ЧПУ | Пента Юниор` (53 символа)
- ✅ `СОЖ для металлообработки: ЧПУ, фрезерование, шлифовка | Пента Юниор` (67 символов)

## Формула удлинения

1. Сохранить начало: `[Тема категории] для [базовое применение]`.
2. Добавить через двоеточие или запятую 2–3 конкретные операции/области: `ЧПУ, фрезерование, шлифовка`, `сверление, резьба, шлифовка`.
3. Оставить бренд-суффикс `| Пента Юниор`.

Целевой диапазон: 60–70 символов.

## Когда не трогать подкатегории

Если пользователь прямо говорит «для этой категории просто title подправь, подкатегорию тоже можешь не исправлять»:

- обновлять только `meta_title` (и при необходимости `meta_description`) у категории;
- не менять `meta_title`/`meta_description` у подкатегорий этой категории без нового согласования;
- не трогать товары.
