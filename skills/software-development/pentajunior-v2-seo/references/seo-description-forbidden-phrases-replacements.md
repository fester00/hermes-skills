# Запрещённые обороты в description и формулы замены

Правило применяется к `meta_description` категорий, подкатегорий **и товаров**.

## Что нельзя упоминать

| Запрещено | Где встречается | Почему |
|---|---|---|
| Цена в любом виде | `от 590 ₽/кг`, `цена от …`, `₽/шт` | description — функциональный/коммерческий текст; цена должна быть только на карточке товара |
| «материал дышит» / «кожа дышит» | гидрофобизаторы, пропитки для обуви | биологический/разговорный оборот, некорректно для технических материалов |
| «разведение» / «разводится» | смывки высолов, СОЖ, концентраты | звучит как бытовая подготовка краски; для профессиональных материалов — более точные формулировки |

## Чем заменять

### Цена

- Просто убрать ценовой блок.
- В конце description вместо цены добавить коммерческий CTA: `Купить.`, `Купить в Москве.`, `Заказать оптом и в розницу.`.

### «Материал дышит» / «кожа дышит»

| Исходный оборот | Замена | Пример |
|---|---|---|
| материал «дышит» | паропроницаемый | Гидрофобизатор сохраняет паропроницаемость поверхности. |
| материал дышит | воздухопроницаемый / сохраняет воздухопроницаемость | Пропитка для обуви сохраняет воздухопроницаемость замши и кожи. |
| кожа дышит | не нарушает воздухообмен | — |

### «Разведение» / «разводится»

| Исходный оборот | Замена | Пример |
|---|---|---|
| разведение 1:2–1:10 | концентрат, разбавляется водой в нужной пропорции | Смывка высолов — концентрат, разбавляется водой перед нанесением. |
| разводится 1:50 | смешивается с водой 1:50 | СОЖ ТЕХМОЛ Экстра — синтетический концентрат, смешивается с водой 1:50. |
| разведение водой | готовая к применению / рабочий раствор готовится добавлением воды | — |

## Где ещё искать остатки запрещённых оборотов

Правило касается не только `meta_description`, но и других пользовательских полей, которые отображаются на странице и могут быть просканированы поисковыми системами:

| Поле | Таблица | Что проверять | Как заменить |
|---|---|---|---|
| `features` | `products` | «Разводится 1:10», «Разведение 1:2–1:10», «Материал дышит» | Заменить на функциональные характеристики: «Концентрат 65%», «Концентрат, разбавляется водой», «Паропроницаемый». |
| `seo_text` | `categories`, `subcategories` | «разводится водой», «материал дышит», ценовые блоки | Заменить на «смешивается с водой», «паропроницаемый», убрать цену. |

**Важно:** если пользователь просит «сео текст не меняй пока что» — трогать `seo_text` нельзя; исправляем только `meta_title`, `meta_description` и `features` (последнее — по согласованию, если оно не влияет на отображаемый SEO-текст).

## Быстрый тест

Перед коммитом проверить `meta_description`, `features` и `seo_text` на запрещённые обороты:

```bash
cd /home/natan/pentajunior-v2
python3 - <<'PY'
import sqlite3, re
conn = sqlite3.connect('pentajunior.db')

def check(table, name_col, cols):
    cur = conn.execute(f"SELECT {name_col}, {', '.join(cols)} FROM {table}")
    for row in cur:
        name = row[0]
        text = ' '.join(str(x or '') for x in row[1:]).lower()
        hits = []
        if re.search(r'₽/|цена', text): hits.append('цена')
        if 'дышит' in text: hits.append('дышит')
        if 'разведение' in text or 'разводится' in text: hits.append('разведение')
        if hits:
            print(f"{table}.{name_col}='{name}': {', '.join(hits)}")

check('products', 'name', ['meta_description', 'features'])
check('categories', 'slug', ['meta_description', 'seo_text'])
check('subcategories', 'slug', ['meta_description', 'seo_text'])
conn.close()
PY
```

Вывод должен быть пустым. Если есть совпадения — переписать по формулам выше.

**Ложные срабатывания:** слово «от» в фразах «защита от воды», «удаление от масла» — нормально. Проверяйте именно ценовые паттерны (`₽/`, `цена`, `от \+ цифра`).

## Примеры применения

### Гидрофобизатор Пента-811

- ❌ `...Материал «дышит». Цена от 590 ₽/кг.`
- ✅ `...Защищает бетон, кирпич, камень, плитку и фасады от влаги, грибка и высолов на 10+ лет. Паропроницаемый. Купить.`

### Смывка высолов Пента-870

- ❌ `...Разведение 1:2–1:10. Цена от 730 ₽/кг.`
- ✅ `...Удаляет высолы, соли, цементный налёт с кирпича, бетона, плитки, камня и фасадов. Концентрат, разбавляется водой. Купить.`

### СОЖ ТЕХМОЛ Экстра

- ❌ `...Разводится 1:50, биостабильный, без хлора.`
- ✅ `...Смешивается с водой 1:50, биостабильный, без хлора. Официальный дистрибьютор ООО «ТЕХГРАНТ». Купить.`

### Пропитка для обуви Пенталюкс

- ❌ `...Кожа дышит, экономичный расход. 400 мл. Купить.`
- ✅ `...Защита кожи, замши, нубука от влаги, соли и грязи. Сохраняет воздухопроницаемость. Купить.`
