# Формула keywords и правила контента для pentajunior-v2

Зафиксировано на основе рабочих сессий по SEO-оптимизации категории «Силикон для заливки форм», «Разделители и смазки для форм» и связанных товаров.

## Формула keywords для товара

Структура (5–7 запросов):

1. **Марка / название товара** — обязательно, если у товара есть брендовое имя (`Юнисил 9500`, `Пента-107`, `Si-M`).
2. **Тип / технология** — общий профессиональный термин (`RTV-2`, `платиновый силикон`, `оловянный силикон`, `аэрозольный разделитель`, `водный разделитель`).
3. **Целевое применение** — 1–2 запроса, отражающих задачу пользователя (`силикон для кукол`, `силикон для гипса и воска`, `разделитель для силиконовых форм`, `смазка перед покраской`).
4. **Коммерческий/общий запрос** — `купить`, `двухкомпонентный силикон`, `разделительная смазка купить`.

### Примеры

| Товар | Keywords |
|---|---|
| Юнисил 9500 | `Юнисил 9500`, `платиновый силикон`, `RTV-2 для кукол`, `силикон для реборн`, `силикон для протезов`, `двухкомпонентный силикон` |
| Юнисил 9110 | `Юнисил 9110`, `RTV-2 силикон для форм`, `силикон для гипса и воска`, `оловянный силикон для заливки`, `двухкомпонентный силикон` |
| Силиконовая смазка Si-M | `Si-M`, `силиконовая смазка аэрозоль`, `аэрозольный разделитель для форм`, `силиконовая смазка для форм`, `разделитель для ПУ и гипса` |
| Касторовая смазка КС-М | `КС-М`, `касторовая смазка`, `натуральный разделитель для форм`, `смазка перед покраской`, `касторовое масло для форм` |

## Чего избегать в keywords

- **Технические спеки вместо применения.** Не использовать `10 Шор А`, `20 Шор А`, `70 Шор D` в keywords — эти параметры лучше оставить в карточке товара. Пользователь редко ищет по цифре твёрдости, чаще — по задаче.
- **Слишком общие наборы у всех товаров подкатегории.** Если у 3+ товаров одинаковые keywords, поисковик не видит разницу между ними.
- **Пищевая промышленность / медицина / FDA / BfR** — прямые упоминания разрешены только для продукции, которой это действительно свойственно. На момент сессий единственный такой продукт — **ТСМ-1** (антипригарный материал). Для силиконовых трубок можно сохранить формулировку «пищевые и медицинские» как фактическое описание материала, но не раздувать акцент.
- **«От производителя»** там, где компания не производит. Для дистрибьюторских линеек (СОЖ/ТЕХМОЛ Экстра, Силагерм и др.) использовать «официальный дистрибьютор» или убрать производственную формулировку.

## Title и description

- `meta_title` — **60–70 символов**. Целиться в 60, 70 — редкий потолок. Не добавлять «от производителя» в статические страницы без проверки: Пента Юниор — дистрибьютор ряда линеек.
- `meta_description` — **160–170 символов (включая пробелы)**. Уточнено в сессии 2026-07-13: лимит расширен с ≤160 до 160–170 для лучшего раскрытия сниппета.
- Усиливать **семантическую связь** между title, description, keywords, H1 и видимым контентом: повторять марку/тип/применение, добавлять второстепенные применения и коммерческий сигнал (`купить`, `доставка`, `Москва`).
- **Акцент на функционально-предметном применении**, а не на технических характеристиках. Указывать, для чего и под что используется товар: `для заливки форм под гипс`, `для опалубки и бетона`, `для кукол и протезов`, `для ювелирных форм и эпоксидной смолы`. Чем конкретнее предметная задача, тем лучше.
- **Форма выпуска.** Слово «аэрозольный» заменять на **«в аэрозольной упаковке»** — установленная в проекте конвенция. Не использовать в `meta_title` и `meta_description` слово «аэрозольный» для обозначения формы выпуска.
- **Технические спецификации в `meta_description` товара** (`разводится 1:10`, `взрывобезопасна`, `до +200°C`, `70 Шор D`, конкретные значения вязкости в сСт) не дублировать, если они уже есть в карточке товара. Эти параметры не несут поискового веса и занимают место в сниппете. Исключение — если параметр сам является частым поисковым запросом. Вместо этого добавлять целевые сигналы применения: типы форм, материалы, отрасли, марки.
- Для прозрачных/ювелирных силиконов: `ювелирные формы`, `бижутерия`, `смолы`, `имитация стекла`.
- Для бытового/хоббийного применения: `куклы`, `реборн`, `мыло`, `свечи`, `гипс`, `воск`.
- Для промышленного применения: `опалубка`, `бетон`, `пресс-формы`, `ПУ-смолы`, `эпоксидная смола`.

## Статические страницы и сильные мета-источники

Помимо SQLite, проверять и править статические `page.tsx`, `layout.tsx`, `syte-config.ts`:
- `src/app/page.tsx` — title/description/openGraph/JSON-LD WebPage/H1;
- `src/app/production/page.tsx` — og:title/og:description часто берутся из `CONFIG.description` и оказываются короткими;
- `src/app/price/page.tsx`, `src/app/info/faq/page.tsx`, блог-статьи `src/data/blog/article-*.ts`.

Распространённая ошибка: `og:description` на `/production` подтягивает короткий `CONFIG.description` вместо полного `meta_description`. Исправлять явно в `openGraph`/`twitter` объектах `metadata`.

## Производитель vs дистрибьютор

| Ситуация | Формулировка |
|---|---|
| Пента Юниор производит | можно «от производителя» |
| Пента Юниор — официальный дистрибьютор | «официальный дистрибьютор ООО «ТЕХГРАНТ»» |
| Неясно | безопаснее убрать «от производителя», заменить на «купить» или «в Москве» |

## Рабочий workflow по категории

1. Извлечь из SQLite: категорию, подкатегории, товары.
2. Проверить длины title/description и наличие проблемных формулировок.
3. Составить черновик по формуле выше.
4. Показать пользователю и получить «давай».
5. Backup БД → применить правки → build gate → commit/push.
6. Деплой только по команде «задеплой».
