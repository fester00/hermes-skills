# Рецепт SEO-оптимизации товаров pentajunior-v2

Краткая инструкция и шаблоны для обработки одной подкатегории товаров.

## Общие правила

1. **Функционально-предметная семантика** — в `meta_title`, `meta_description`, `keywords` и `H1` товара должно быть не только название/марка, но и **конкретное применение**: «для заливки форм под гипс и смолы», «для опалубки и бетонных форм», «для кукол и протезов» и т.п.
2. **Title**: 60–70 символов. Марка — тип/свойство — применение — `| Пента Юниор`.
3. **Description**: 160–170 символов (включая пробелы). Содержит: марка + тип + основное применение + второстепенное применение + коммерческий CTA. См. `references/seo-description-forbidden-phrases-replacements.md`.
4. **Keywords**: 5–6 штук. Марка + термин типа + применение 1 + применение 2 + коммерческий/расширяющий запрос.
5. **Не писать в description технические параметры**: вязкость в сСт, твёрдость по Шору, температурные диапазоны, разведение 1:10 — эти данные оставить в карточке товара.
6. **Запрещённые обороты в description.** Не упоминать цену, не использовать «материал дышит»/«кожа дышит», не писать «разведение»/«разводится». Замены: паропроницаемый, воздухопроницаемый, сохраняет воздухопроницаемость, концентрат, смешивается с водой, разбавляется водой.
7. **Аэрозольная упаковка**: вместо «аэрозольный» используй формулировку «в аэрозольной упаковке» или «в аэрозоле".
8. **Последовательность**: категория → подкатегория → товары. Показать черновик → одобрение → backup БД → UPDATE → проверка длин → `seo_jsonld_audit.py` → build gate → commit → push.

## Шаблон формулировок

### Силиконы RTV-2

- **Title**: `Марка — тип силикона для применения | Пента Юниор`
- **Description**: `Марка — платиновый/оловянный RTV-2 силикон для заливки форм. Для [гипса, смол, воска, мыла, бетона, кукол, протезов]. Двухкомпонентный компаунд. Купить от 1 кг.`
- **Keywords**: `Марка`, `платиновый/оловянный силикон`, `RTV-2 для [применение]`, `силикон для [материал]`, `двухкомпонентный силикон`.

### Полиуретаны

- **Title**: `Марка — жидкий/прозрачный/эластичный полиуретан для применения | Пента Юниор`
- **Description**: `Марка — [тип] полиуретан для заливки форм/отливок. Для [декора, деталей, прототипов, бетона, гипса]. [свойство]. Купить от 1/2 кг.`
- **Keywords**: `Марка`, `жидкий полиуретан`, `полиуретан для [применение]`, `[свойство] полиуретан`, `полиуретан купить`.

### Масла ПМС

- **Title**: `Масло ПМС-N — силиконовое, N сСт, для применения | Пента Юниор`
- **Description**: `Силиконовое масло ПМС-N, N сСт. Для [смазки, гидравлики, вискомуфт, приборов, косметики]. [свойство: стабильная вязкость, термостойкость]. Купить.`
- **Keywords**: `ПМС-N`, `силиконовое масло N сСт`, `масло для [применение]`, `полиметилсилоксан купить`.

### Разделители и смазки

- **Title**: `Название — разделитель/смазка для применения | Пента Юниор`
- **Description**: `Название — [водный/восковый/касторовый/силиконовый] разделитель для [форм, опалубки, бетона, ПУ, гипса]. [свойство: чистый съём, экономичный расход]. Купить.`
- **Keywords**: `Название`, `[тип] разделитель`, `смазка для [применение]`, `разделитель для форм`, `смазка купить`.

### Герметики

- **Title**: `Марка — [нейтральный/кислотный/термостойкий] герметик для применения | Пента Юниор`
- **Description**: `Марка — силиконовый герметик для [электроники, стекла, автомобилей, печей]. [свойство: УФ-стойкий, до +300 °C, маслобензостойкий]. Купить.`
- **Keywords**: `Марка`, `силиконовый герметик`, `герметик для [применение]`, `[свойство] герметик`, `герметик купить`.

## Замены запрещённых оборотов

См. `references/seo-description-forbidden-phrases-replacements.md`. Кратко:

| Запрещено | Замена |
|---|---|
| цена / `от … ₽` | убрать; в конце `Купить.` |
| «материал дышит» | «паропроницаемый», «сохраняет воздухопроницаемость» |
| «разведение» / «разводится» | «концентрат», «смешивается с водой», «разбавляется водой» |

## Частые ошибки

- Затереть `title` в `categories`/`subcategories`, обновляя только `meta_title`/`meta_description`.
- Вывести description за 170 символов, добавляя «доставка по России» в конец уже длинной строки.
- Использовать в keywords технические параметры (`70 Шор D`, `100 сСт`).
- Оставить в title слово «купить» в середине: плохо для читаемости, бренд и CTA должны быть в конце.
- Пропустить цену, «дышит» или «разведение» в description товара — проверять скриптом из `references/seo-description-forbidden-phrases-replacements.md`.
